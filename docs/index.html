Set the board’s time zone.

Use the time zone where the lock will be installed. Keep its current rules or save a new setting.

Current board setting: Not checked

For example, UTC0 for UTC or EST5EDT,M3.2.0/2,M11.1.0/2 with daylight-saving rules. Use a POSIX rule, not a city name.

This uses today’s fixed UTC offset, without daylight-saving changes.

This step does not verify an existing lock’s clock. Sync and check it in the board’s interface before relying on schedules.

Supported hardware

Classic ESP32 images need 4 MB flash; ESP32-S3 images need 8 MB and native USB. Both expect the confirmation button on GPIO0. M5 ATOM (GPIO39) and AtomS3 (GPIO41) need a custom build. ESP8266 has no Bluetooth; ESP32-C3, C6 and H2 builds are not provided.

Privacy & recovery

Your backup is read locally and sent to the board over USB. This page does not upload credentials or backups, or save them in browser storage. Keep your encrypted backup and its passphrase somewhere safe. A backup does not replace a physical key.
